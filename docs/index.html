How to use

Prompts Copy any .md from prompts/ and paste as a system prompt in ChatGPT, Claude, or Gemini. Then give it your context.
Skills Copy any file from skills/ to your ~/.claude/skills/ directory. Invoke with /skill-name in Claude Code.
Career Start with career-profile-builder.md — it guides you through building a Master Profile, then hands off to tailoring and job fit.
